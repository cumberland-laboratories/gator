Summary

Paste the prompt into your coding agent. The agent runs gator init and completes the required reads before it does substantive work.

How a session starts

  1. Paste the prompt below into the coding-agent session for the repository.
  2. The agent runs gator init.
  3. The output names the Gator entry document (GATOR_INIT.md) and the required reads.
  4. The agent completes those reads before it does substantive work. Then you give the task.

The session-opening prompt

Run gator init in this repository. Treat its output, including the required session-opening reads, as binding. Do not provide a substantive response until those reads are complete.
