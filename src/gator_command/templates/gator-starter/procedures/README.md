# Procedures

Repeatable workflows that have stabilized. A procedure is a step-by-step process that you or an AI agent can follow consistently — the kind of thing you'd otherwise explain from memory each time.

## When to create a procedure

- A workflow has been done 2-3 times and the steps are stable
- You want an AI agent to follow a specific process without improvising
- A task has enough complexity that getting the order wrong causes problems

## How to create one

Ask your AI coding agent:

> "We've done [this workflow] a few times now. Write it up as a procedure."

Or after completing a complex task:

> "Document what we just did as a procedure for next time."

## What makes a good procedure

- Clear trigger: when should this procedure be used?
- Numbered steps: unambiguous order of operations
- Checkpoints: places where the human should verify before continuing
- Short: if it's longer than a page, it might be two procedures

## What procedures are not

Procedures are not reference material (use reference-notes), not design rationale (use artifacts), and not one-time instructions. They are reusable processes.
