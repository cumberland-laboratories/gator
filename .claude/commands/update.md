Run the Gator template update by executing: `gator update` (requires the Gator CLI — `pipx install gator-command`; pre-2.9 repos may still carry a runnable `gator-update.py` in `.gator/scripts/` or `.gator/.includes/scripts/`).

This refreshes template-derived files (constitution, procedures, scripts, reference-notes, charter templates, slash commands) without touching any user content (charters, threads, artifacts, mission, roadmap, etc.).

Display the output showing what was added, updated, or unchanged. If the Architect wants to preview first, use `--dry-run`.
