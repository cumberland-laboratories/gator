What this shows

Each node is a chartered region of Gator — a semantic module whose contract is documented in .gator/charters/. Each edge is a declared cross-region relationship taken from the charters' ## Connections sections, function-entry ←/→ markers, or cross-cutting tripwires. The map is an orientation surface: it answers "what are the parts, and how do they hang together?" It is not a precision runtime call graph — mixed edge types (runtime, governance, packaging, conceptual) are drawn uniformly at Level 1.

Why these regions exist

  • Cross-Cutting is the governance spine: shared invariants across every script (charter-surface resolver, import convention, git contracts, schema discipline).
  • Core Library is the shared runtime other scripts depend on (version resolution, repo discovery, dashboard registry, git helper).
  • Contracts and Release Pipeline are boundary surfaces that gate what leaves the wheel and how.
  • Layout Resolver, Installer & Boot, Managed State, and Repo Lifecycle are the day-2 operations layer.
  • Dashboard, Session Archaeology, and Fleet Intelligence are the analysis and reporting surfaces.
  • Gator Loop is the multi-agent planning protocol; Enterprise is the optional capability layer.

Reading order

  1. Start with the Cross-Cutting node — its charter defines the invariants every other charter builds on.
  2. Follow the edges outward from Core Library — most other regions depend on it.
  3. Trace Installer & Boot → Repo Lifecycle to see the day-2 flow.
  4. Trace Dashboard ← Fleet Intelligence ← Session Archaeology to see the analysis flow.

Boundaries and tripwires

  • The map deliberately shows declared relationships, not observed code references. If a charter says a region depends on another, that edge exists here; if a runtime import exists that no charter declares, it does not appear at Level 1 (drift belongs to a future Level 4 view).
  • Enterprise is intentionally on the periphery: it is a source-checkout-only capability, not part of the base wheel's runtime chain.
  • Contracts and Release Pipeline are drawn on the boundary to signal that they gate the wheel's public surface — changes there ripple through every other region's shipping story.

Open questions

  • Are there charter regions whose declared connections have drifted from actual code references? (Future L4 drift map territory.)
  • Which of these regions have the highest tripwire density, and does that predict where changes should be reviewed more carefully?
